# Промпт для Claude Design

Спроектируй **Mac Island**: «динамический островок» для MacBook с челкой (MacBook Pro 14"/16", M-серия). Это нативное macOS-приложение. Чёрная плашка сливается с аппаратной челкой сверху по центру экрана, а при наведении курсора плавно раскрывается вниз, как Dynamic Island на iPhone. Островок показывает сессии AI-агентов. В первой версии это сессии **Claude Code**, которые запущены в терминалах.

## Что показать

Каждый вариант рисуй **в контексте реального Mac**. Нужен фрагмент экрана MacBook Pro 14" (3024×1964, показывай верхнюю часть рабочего стола) с:
- аппаратной челкой (≈200×32 pt, скруглённые нижние углы);
- строкой меню macOS (слева Apple-меню и меню приложения, справа иконки статуса и часы);
- обоями и куском окна терминала/IDE под островком, чтобы было видно масштаб и как островок перекрывает контент.

Для каждого варианта покажи **три состояния на одном экране** (сверху вниз или рядом):
1. **Свёрнутое (idle/compact).** Плашка лишь чуть шире челки. Слева маленький индикатор (логотип Claude или цветная точка), справа счётчик активных сессий. Никакого текста, который мешал бы строке меню.
2. **Свёрнутое с алертом.** Одна из сессий ждёт ответа или разрешения пользователя. Островок привлекает внимание: пульсирующее свечение, оранжевый акцент или кратко выдвинутая строка «Claude needs permission · my-project».
3. **Раскрытое (hover).** Панель шириной ~360–440 pt вырастает из челки вниз, с непрерывным чёрным фоном и большими радиусами скругления. Внутри список сессий:
   - название проекта (папка `cwd`) и ветка git;
   - статус: 🟢 Working (+ текущее действие, например «Editing src/App.swift» или «Running npm test»), 🟠 Waiting for input / Needs permission, ✅ Done (+ «2m ago»), ⚪ Idle;
   - время работы сессии;
   - у сессии в статусе «Needs permission» есть кнопки **Allow** / **Deny** и превью команды, на которую спрашивается разрешение;
   - клик по строке ведёт в терминал этой сессии (покажи hover-состояние строки).

## Варианты (сделай 4 разных направления)

1. **Apple-native.** Максимально близко к iOS Dynamic Island: чистый чёрный, SF Pro, SF Symbols, системные цвета статусов, минимум декора.
2. **Claude-branded.** Тёплый акцент Claude (терракотовый/оранжевый), маленький анимированный логотип-«искра» в свёрнутом состоянии, который «дышит», пока агент работает.
3. **Dense / dev-tool.** Моноширинный шрифт, компактные строки, больше информации: токены, стоимость, последний инструмент, мини-лог последних 3 действий. Для тех, кто держит 5+ сессий.
4. **Glanceable / ambient.** Минимум текста. Состояние передаётся цветом, формой и анимацией: прогресс-кольца, полоски активности по краю островка. В раскрытом виде карточки сессий вместо списка.

## Требования

- Тёмная тема в приоритете: островок всегда чёрный, чтобы сливаться с челкой. Покажи, как он выглядит на светлых и на тёмных обоях.
- Островок не должен закрывать иконки строки меню в свёрнутом состоянии.
- Покажи анимацию раскрытия раскадровкой из 3–4 кадров (compact → morph → expanded) хотя бы для одного варианта.
- Подпиши ключевые размеры (высота compact, ширина expanded, радиусы, отступы), чтобы это можно было сразу перенести в SwiftUI.
- Если раскрытый список длинный (8+ сессий), покажи скролл или группировку («Needs attention» сверху).

В конце дай короткую сравнительную таблицу вариантов: плюсы, минусы, для кого подходит.
